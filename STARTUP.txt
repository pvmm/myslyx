Welcome to Myslyx Text Editor.

- Use the '+ NEW' button to create files.
- Click a file in the dock to open it.
- Drag-and-drop text files onto the editor page to import.
- Use the toolbar for Rename/Delete.
- Use the "EXPORT SYMBOLS" button to share through autocomplete the declared symbols.
- Toggle wrap around in the editor with the "WRAP OFF/WRAP ON" button.
